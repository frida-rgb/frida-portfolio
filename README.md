# Frida Freelance Portfolio

A responsive, static portfolio website built with HTML and CSS (plus a tiny script for the mobile navigation). It is designed to be published for free with GitHub Pages.

## Files
- `index.html` — website content and sections
- `styles.css` — layout, colors, and responsive styles
- `cv.pdf` — optional; add your own PDF CV with this exact filename

## Before publishing
1. Replace `your.email@example.com` with a public professional email address.
2. Update the LinkedIn and freelance profile links.
3. Add `cv.pdf` to this folder if you want the CV button to work.
4. Check every skill and service; remove anything you cannot confidently offer.
5. The project cards are explicitly labelled **SAMPLE PROJECT**. Keep that label until you replace each demo with work you actually completed. Do not upload employer/client confidential information.

## Publish on GitHub Pages
1. Create a public repository named exactly `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and optionally `cv.pdf` to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose branch `main`, folder `/ (root)`, then save.
5. Wait for deployment. The website URL should be `https://YOUR-USERNAME.github.io`.

## Customization
Edit the HTML text directly on GitHub by opening a file and clicking the pencil icon. Commit changes to publish the update. Edit colors near the top of `styles.css` under `:root`.

Note: the page imports Google Fonts from an external service. If you prefer no external font requests, remove the `@import` line; the page will use the fallback sans-serif font.
